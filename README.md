# Diana Sichanhová – CV website

My personal CV website. It shows my skills, school projects from FIT CTU in Prague and my education.

**Live:** https://ohmydiana.github.io/cv/

## Built with

Plain HTML, CSS and JavaScript.

- mobile-first responsive layout
- print styles, so the page prints as a two-page CV
- small amount of JS for the header, active navigation link and scroll animations

## Structure

```
index.html       home page – about, skills, projects, education, contact
projects.html    all my school projects
styles/          CSS, split by purpose and imported in main.css
js/main.js       header and scroll behaviour
pics/            photo, icons, favicon
```

## Running locally

Open `index.html` in a browser, or start a local server:

```bash
python3 -m http.server
```

and go to http://localhost:8000.
